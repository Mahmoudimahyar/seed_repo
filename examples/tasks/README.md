# Local task-plan example
This plan is deliberately unapproved. It is not evidence of a person's consent.
Preview with `python3 scripts/seed_tasks.py --plan examples/tasks/plan.json`.
For a real project, copy and edit the plan, record actual scoped approval separately,
and invoke `--execute` only after reviewing the exact commands. Do not run a copied
plan with production credentials. Only one local runner per checkout can hold its lock.
See [resumable execution](../../docs/workflows/execution.md).

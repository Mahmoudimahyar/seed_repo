# 0.3.0-rc.1 — decision planning and bound scope approval

This release adds an optional local decision map, outcome-aware prerequisites, precise
question/fog/exclusion separation, source/policy/dependency freshness, recorded human-owner
checks, compare-and-set revisions, local leases, history, export/import and bounded handoffs.
It adds seed-wayfind and seed-plan-review and extends existing discovery/recovery skills.
The MCP adapter adds one read-only planning_handoff tool; it does not expose planner writes.

**Compatibility change:** readiness uses schema_version 2 and must be bound to the exact
reviewed evidence. Existing schema-1 approvals are BLOCKED until explicit migration and
actual reapproval. Application task plans need readiness_sha256 plus matching scope, checked
before and after each command. The original template-maintenance path remains unchanged.

The accepted proposal's local functionality is implemented. The optional remote tracker
adapter and controlled model-versus-model/old-versus-new workflow benchmark remain deferred;
no tracker was selected or authorized. Local tests are not a claim of distributed safety,
authenticated human consent, a complete semantic proof or measured token reduction.

See [validation](../validation.md), [upgrade instructions](../upgrading.md), and
[planning](../workflows/decision-planning.md). GitHub hosting, publication, external model
calls and production deployment were not performed by generating this release.

# Seed Repo 0.5.0-rc.1

Public-upload release candidate: consolidates the prior 0.4 capabilities and applies the
reviewed SDD/TDD refinements without another specification framework or plugin bundle.

## Changes
- Precise behavioral contracts and nonbinding implementation sketches in existing templates.
- Stable test plans; results and reconciliation in separate execution evidence.
- Optional namespaced requirement/JUnit maps in active features, with strict schema/ID checks.
- Fresh bounded test execution, explicit missing/skipped/error/manual/observation states,
  source/result/configuration fingerprints, and automatic application-profile consumption.
- Legacy characterization and intended/observed distinctions inside existing discovery.
- Current public publishing instructions, preserved history/licensing, pinned actions.

No model/provider/deployment is installed or enabled implicitly. No new MCP server is added.
Keep the existing deterministic-first, reuse-first, TDD, scoped approvals, external-source
verification, graph freshness and GitHub delivery controls.

## Validation and limitations
Read docs/validation.md for actual local commands and results. The optional official MCP
transport/providers, hosted GitHub matrix, native coding clients, live model comparisons and
independent security review require external acceptance. Local traces are integrity records,
not signatures or human authentication. A mapped test is not proof its assertion is correct.

## Adoption
This is a whole repository, not an add-on. Do not initialize the maintainer publishing checkout
as an application. Existing adopters should review docs/upgrading.md and integrate on a branch.
Do not move published tags. New active verification maps need ordinary specification review.

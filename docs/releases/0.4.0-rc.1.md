# 0.4.0-rc.1 — verified source research, optional structural analysis

This additive release integrates source-first reuse with the existing scope, task, recovery,
retrieval and export boundaries. It does not install providers or replace first-party GraphRAG.

## Added
- Optional bounded source CLI: local import, opensrc acquisition, exact Git commit archive,
  compare, explicit mapping review, cache restoration, source search/read and task binding.
- Registry/request schemas; sanitized tracked identities; isolated local source and graph caches.
- Optional pinned Graphify AST-library worker with explicit code paths, clean environment,
  disabled Python networking/processes, finite resources and partial-extraction reporting.
- Derived graph freshness, bounded literal/neighborhood queries, per-source namespaces.
- Task input verification before resume/steps and after commands; checkpoint/status consumers.
- Actual optional-provider acceptance checker and three-arm research/evaluation scenarios.

## Changed
Research/reuse, implementation, simplification and recovery skills now use this capability only
when needed. Application scope binds registered manifests/review evidence; public template export
requires an empty registry. Defaults do not add Node, Graphify, providers, MCP tools, marketing,
or downstream CI requirements. Existing applications must follow the upgrade guide.

## Evidence boundaries
See [validation](../validation.md) for executed results. Real local Git and subprocess tests are
separate from labeled synthetic opensrc/Graphify protocol doubles. Upstream installed-provider,
MCP/client, hosted CI, Windows/macOS and real coding-cost comparisons are not certified here.
No performance or token saving is promised. Local hashes/reviews are not authenticated consent
or publisher attestations. The Python audit guard is not an OS/native-code sandbox.

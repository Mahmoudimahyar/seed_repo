# Seed Repo 0.1.0-rc.1

A stack-neutral starting point for research-first, evidence-driven AI-assisted software
projects. Includes focused discovery/engineering skills, safe local initialization,
project documentation templates, a tested CI command runner, and GitHub collaboration
configuration and guides.

Start with README.md and START_HERE.md. Use the repository template button to begin your
own project; fork to contribute upstream. Marketing and sales are opt-in.

This is a prerelease developer-tooling/documentation kit, not a prebuilt application or
a hosted AI service. GraphRAG/MCP and automated benchmark/model-promotion systems are not
implemented here. Client behavior, application tests, server-side GitHub protections,
and deployments require separate verification.

Before publishing these notes, the maintainer must add verified hosted-run references
and platform/client results, or explicitly retain their NOT_RUN status. See docs/status.md
and docs/validation.md for the preparation-time testing boundary.

# Integration strategy
Use existing maintained APIs, SDKs and services before inventing custom integrations.
Review exact versions, license, security, privacy, cost thresholds and exit strategy.
The local [MCP adapter](mcp.md) is optional. Hosted deployment and provider adapters depend
on the adopter's stack and account; see [status](../status.md). No paid services, telemetry,
remote skills, or plugins are installed without explicit approval.

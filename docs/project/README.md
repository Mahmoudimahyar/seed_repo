# Your project documents

This directory is intentionally unfilled in the public template. After the project mode
and capabilities are agreed, run the initializer through [getting started](../getting-started.md).
It creates the relevant documents with explicit unfilled markers and open gates.

These are your application/tool specifications, not Seed Repo's own marketing material.
Use stable requirement/flow/test IDs, link source evidence, and keep one authoritative
record for each fact. Raw private intake belongs outside public Git.

# Support

Start with [getting started](docs/getting-started.md), [agent setup](docs/agents.md),
[troubleshooting](docs/troubleshooting.md), and [capability status](docs/status.md).

For reproducible starter defects, open an issue using the bug template. Include the Seed
Repo version, OS, Python version, command, expected/actual result, and sanitized output.
For product ideas, use the task/proposal template. Use Discussions for general questions
when maintainers enable them. Do not paste private intake or secrets.

Seed Repo cannot guarantee a particular model follows instructions or a third-party MCP
server is available. Report failures with the actual tool configuration and evidence.
Generated-application bugs belong in that application's repository unless the starter
itself caused a reproducible defect. There is no promised support SLA.

# Wayfinding behavior scenarios — NOT a completed model benchmark

These 12 synthetic development fixtures state expected planning decisions. They are
compatible with the exact JSON scorer, but exact-match routing alone does not establish
real-world quality. No live model/provider or agent was called to produce this release.

For a controlled comparison, pin the client/model/tools, starting repository snapshot,
permissions, budgets and repeatable user-answer script. Compare the prior and new workflow,
repeat trials, inspect actual actions and final artifacts, and include interruption/ambiguity
scenarios. Track missed blockers, unnecessary questions, unsupported decisions, unauthorized
actions, correct scope, rework, total cost/time and human review effort. Do not promote a
skill solely for matching these visible development answers. Maintain independent held-out
scenarios and protect evaluation criteria from the implementation agent.

Deterministic unit/integration tests cover many bookkeeping and rejection paths separately;
those results do not prove an LLM follows the skill or achieves token savings.

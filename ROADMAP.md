# Roadmap and non-goals

This release delivers a small, testable baseline. Improvements should be justified by
actual task evaluations, maintainability and user value, not by adding frameworks.

Potential future work: evaluated language-server integrations for more languages;
measured incremental indexing; privacy-safe external provider adapters; protected-domain
scorers and held-out evaluations; deployment adapters for specific stacks; stronger
trusted gateway integrations. These are NOT required before starting a small project.

No universal company structure, automatic paid cron, automatic skill/model promotion,
mandatory graph database, model leaderboard promises, or thousands-agent scheduler is
installed. Keep research choices, client support and security advisories current through
reviewed changes and CI. Public contributions follow the existing GitHub policies.

Delivered in 0.3.0-rc.1: optional local decision maps, typed outcome-aware dependencies,
revision-bound recorded approval, local claims/history and exact handoff selection.
Deferred deliberately: live-agent A/B workflow evaluation and a selected remote tracker
adapter with tested distributed semantics. No backend is installed merely to satisfy a
future scale aspiration.

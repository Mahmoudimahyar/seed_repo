# seed-improve


Read docs/workflows/skill-improvement.md. Distinguish project facts from reusable procedure.
Check existing skills, propose the smallest change, compare incumbent/no-skill/candidate on
appropriate held-out and regression cases, and record cost plus human review effort.
Keep labels/evaluators/safety boundaries independent from the proposer. Audit model agreements.
Request review before promotion; preserve rollback and sync approved Claude mirrors.
Do not automatically edit active skills or install every GStack/Hermes/Superpowers workflow.

## Integration contract

On skill rename/removal, preview sync-skills retirement. Known unchanged generated mirrors may be retired; manually edited or orphaned copies must be reconciled explicitly. Verify actual client discovery afterward, not just a canonical catalog.

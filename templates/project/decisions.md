## Explicit user approvals

## Optional multi-session questions
Use one authoritative map/backend only if decision dependencies justify it. Keep exact
question IDs and resolution references here rather than copying their status. Distinguish
fixed user decisions, delegated implementation choices, imprecise fog and excluded scope.
